## 🛠️ Stack Tecnológico
* **Framework:** Next.js (App Router) v14
* **Estilos:** Tailwind CSS
* **Backend & Base de Datos:** Supabase (PostgreSQL + Auth)
* **Integraciones:** Jitsi Meet SDK (Video), Recharts (Gráficos), EmailJS (Notificaciones)

---

## ⚙️ Requisitos Previos
Asegúrense de tener instalado en sus equipos:
* [Node.js](https://nodejs.org/) (Versión 18 o superior)
* Git
